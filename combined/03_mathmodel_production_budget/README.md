# 生产-预算优化 — 经管与数学建模综合案例

## 教学知识点
场景：工厂两种产品，收益为连续二次函数；同时受原材料、工时、总预算等多条不等式硬约束。
1. calc-insight-kit：可视化收益曲面，观察收益随产量连续变化规律。
2. logic-opt-kit：定义预算、产能、工时约束，求解最大化总收益。
3. 把可行域多边形、最优产量点叠加可视化；观察约束收紧/放松对最优收益的影响。

## 学习观察要点
1. 提高总预算约束上限，可行域扩大，最优收益上升；
2. 某条资源约束很紧时，最优解被"卡"在该约束边界；
3. 体会现实经济问题：收益是连续函数，但现实世界被大量离散硬性规则限制。

## 适用课程
高等经管数学、运筹学入门、数学建模实训课程。
