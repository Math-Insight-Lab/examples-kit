# 逻辑命题过滤函数定义域演示

## 教学知识点
把数理逻辑命题条件，转化成对自变量的约束集合；在平面上只绘制满足该逻辑条件的函数图像子集。
1. logic-opt-kit：定义复合逻辑条件（与、或、非，不等式谓词），求解满足命题的取值集合。
2. calc-insight-kit：仅绘制满足逻辑条件的那一部分函数曲线/曲面，不绘制条件不成立的区域。

## 学习观察要点
1. 直观看到"逻辑命题如何切割函数定义域"；
2. 打通离散数理逻辑和连续函数分析之间的认知鸿沟；
3. 适合离散数学+数学分析交叉课堂演示。

## 示例命题
$$
(x>1 \land y>0) \lor (x<-1 \land y<0)
$$
只绘制满足该复合逻辑命题的函数部分。

```bash
export PYTHONPATH=.
pip install calc-insight-kit logic-opt-kit numpy matplotlib sympy highspy
```
